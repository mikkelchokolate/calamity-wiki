# Calamity Wiki 2.2.4

Неофициальная справочная вики: 2671 предмет Calamity, 5455 предметов Terraria с иконками, более 4000 рецептов, все пять классов по 20 этапов, 45 боссов и 9 мини-боссов/событий. Основные пояснения и руководства — на русском. Названия Calamity сохранены для поиска в игре; оригинальные подсказки и непроверенные черновики перевода раскрываются отдельно.

Сайт: https://mikkelchokolate.github.io/calamity-wiki/

Можно скачать файлы репозитория и открыть index.html без сервера. Все ресурсы находятся рядом; не переносите index.html отдельно. Избранное и прохождение сохраняются в вашем браузере, отдельно для сайта и локальной копии.

Данные получены статическим разбором отдельной копии установленного Calamity 2.2.4. Начальные характеристики босса приведены для одного игрока; мультиплеер, фазы, настройки и другие моды могут менять результат. Невычисленные динамические свойства помечены. Отсутствие найденного правила не доказывает недоступность предмета. Включены обычные предметы, прямые рецепты Terraria, изменения рецептов Calamity и распознанные правила добычи. Динамические и сложные правила ещё требуют проверки по источнику; полнота каждой игровой ветви не заявляется.

Архив мода, DLL, сохранения и полные декомпилированные исходники в репозиторий не включены. Карточки источников содержат происхождение и контрольные суммы проверенных файлов. Публичная ветка Calamity может отставать от установленной версии.
