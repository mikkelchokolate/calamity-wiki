# Calamity Wiki 2.2.4

Неофициальная справочная вики: 2671 предмет, 2023 рецепта, все пять классов, боссы и сложность, биомы и механики. Интерфейс и авторские руководства — на русском; модовые названия и игровые описания — на английском. Для Terraria используется русская локализация.

Сайт: https://mikkelchokolate.github.io/calamity-wiki/

Можно скачать файлы репозитория и открыть index.html без сервера. Все ресурсы находятся рядом; не переносите index.html отдельно. Избранное и прохождение сохраняются в вашем браузере, отдельно для сайта и локальной копии.

Данные получены статическим разбором отдельной копии установленного Calamity 2.2.4. Начальные характеристики босса приведены для одного игрока; мультиплеер, фазы, настройки и другие моды могут менять результат. Невычисленные динамические свойства помечены. Отсутствие найденного правила не доказывает недоступность предмета. Для ванильных предметов здесь показаны связи и рецепты Calamity, а не полная база Terraria.

Архив мода, DLL, сохранения и полные декомпилированные исходники в репозиторий не включены. Карточки источников содержат происхождение и контрольные суммы проверенных файлов. Публичная ветка Calamity может отставать от установленной версии.
